# Mern-Auth-Template
A production-ready authentication template built with the MERN stack (MongoDB, Express.js, React, Node.js). This boilerplate gives you a solid starting point for building full-stack applications with secure authentication and authorization out of the box.
🔑 Features

🌐 Full MERN Stack (MongoDB, Express, React, Node)

🔒 JWT Authentication (Login, Register, Logout, Tokens)

👤 User Roles & Protected Routes

📩 Password Reset with Email OTP

📂 Tech Stack

Frontend: React + Vite + Tailwind

Backend: Node.js + Express.js + MongoDB + Mongoose

Auth: JSON Web Tokens (JWT) + bcrypt

Extras: Multer for file uploads, CORS enabled, REST APIs

🎯 Why Use This Template?

Instead of writing authentication from scratch every time, use this template as a ready-made foundation.
You’ll save time and can directly focus on building your core features—whether it’s a blog, social media app, SaaS platform, or e-commerce site.
